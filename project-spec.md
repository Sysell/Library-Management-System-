1.1 Название
Library Management System — информационная система для управления библиотечным фондом

1.2 Целевой пользователь
Библиотекари, администраторы библиотек и читатели, нуждающиеся в удобном инструменте для управления книжным фондом, учета выданных изданий и анализа статистики.

1.3 Решаемая проблема
Традиционный способ ведения картотеки библиотеки требует больших временных затрат, подвержен ошибкам и не позволяет быстро найти информацию о наличии книги, истории выдачи или провести аналитику по популярности изданий.



2. ОСНОВНАЯ СУЩНОСТЬ
Сущность: Книга (Book)
Поля сущности:
№	Название поля	Тип данных	Описание
1	ID	Строка	Уникальный идентификатор книги (ISBN или внутренний код)
2	Название	Строка	Полное название произведения
3	Автор	Строка	ФИО автора или авторов
4	Описание	Многострочный текст	Аннотация, краткое содержание книги
5	Количество экземпляров	Число	Общее количество копий в библиотеке
6	Дата поступления	Дата	Дата добавления книги в фонд
7	Статус	Категория	Статус: "Доступна", "Выдана", "На ремонте", "Исключена"
8	Жанр	Категория	Классификация: "Художественная", "Научная", "Учебная", "Справочная"
9	Рейтинг	Число	Оценка читателей (1-5 звезд)
10	Бестселлер	Логическое	Отмечена ли книга как популярная



3. АРХИТЕКТУРА ПРИЛОЖЕНИЯ
3.1 Спроектированные страницы
   
Страница 1: Dashboard (Обзор)
URL: /
Назначение: Главная страница с ключевыми метриками
Отображаемые данные:
- Общее количество книг в фонде
- Количество доступных экземпляров
- Количество выданных книг
- Количество читателей
- Последние добавленные книги
Действия пользователя:
- Просмотр статистики
- Переход к списку книг
- Переход к созданию новой книги

Страница 2: Список книг (Library)
URL: /books
Назначение: Таблица всех книг в библиотеке
Отображаемые данные:
- Название, автор, жанр
- Количество доступных копий
- Статус
- Рейтинг
Действия пользователя:
- Поиск по названию/автору
- Фильтрация по жанру и статусу
- Сортировка по названию, автору, дате
- Переход на страницу подробностей
- Удаление записи

Страница 3: Подробная информация (Book Details)
URL: /books/:id
Назначение: Полная информация о конкретной книге
Отображаемые данные:
- Все поля книги
- История выдачи (кому, когда)
- Отзывы читателей
- Похожие книги по жанру
Действия пользователя:
- Редактирование информации
- Пометка как выданная
- Просмотр истории
- Добавление отзыва

Страница 4: Создание и редактирование (Edit/Add Book)
URL: /books/new и /books/:id/edit
Назначение: Форма для добавления или изменения книги
Отображаемые данные:
- Форма со всеми полями сущности
- Валидация данных
- Подсказки по заполнению
- Действия пользователя:
- Заполнение всех полей
- Загрузка обложки
- Сохранение или отмена
- Удаление черновика

Страница 5: Статистика и аналитика (Analytics)
URL: /analytics
Назначение: Анализ данных о библиотечном фонде
Отображаемые данные:
- Граммика: топ жанров
- Граммика: активность по месяцам
- Список самых популярных книг
- Статистика по авторам
- Процент доступности фонда
Действия пользователя:
- Выбор периода анализа
- Экспорт отчета
- Изменение типа графика

Страница 6: История выдачи (Circulation History)
URL: /history
Назначение: Журнал всех операций выдачи/возврата
Отображаемые данные:
- Дата выдачи/возврата
- Название книги
- ФИО читателя
- Срок возврата
- Задержки
Действия пользователя:
- Фильтр по читателю
- Поиск по названию книги
- Просмотр просроченных
- Печать отчета



4. ПОЛЬЗОВАТЕЛЬСКИЕ СЦЕНАРИИ

Сценарий 1: Добавление новой книги в фонд
1. Библиотекарь открывает приложение
2. Переходит на страницу /books
3. Нажимает кнопку "Добавить книгу"
4. Попадает на форму создания (/books/new)
5. Заполняет все поля: название, автора, описание, жанр, дату, количество
6. Нажимает "Сохранить"
7. Система добавляет книгу в базу
8. Пользователь видит подтверждение и возвращается на список

Сценарий 2: Поиск книги читателем
1. Читатель открывает Dashboard
2. Видит поле поиска
3. Вводит название "Война и мир"
4. Переходит на страницу списка (/books)
5. В результатах видит найденную книгу
6. Видит информацию о доступности и может зарезервировать

Сценарий 3: Выдача книги читателю
1. Библиотекарь на странице подробностей книги (/books/:id)
2. Видит кнопку "Выдать книгу"
3. Нажимает кнопку
4. Вводит ФИО читателя и срок возврата
5. Система сохраняет запись в историю
6. Статус книги меняется на "Выдана"
7. Количество доступных экземпляров уменьшается на 1

Сценарий 4: Просмотр статистики по популярности
1. Библиотекарь переходит на страницу /analytics
2. Видит графики популярности жанров за последний год
3. Вверху страницы выбирает период "Последние 6 месяцев"
4. Графики обновляются
5. Видит, что художественная литература пользуется спросом
6. Нажимает "Экспортировать отчет" для презентации руководству

Сценарий 5: Управление книгой с задержкой возврата
1. Администратор заходит на страницу /history
2. Фильтрует по "Просроченные"
3. Видит список книг, не возвращённых в срок
4. Выбирает конкретную запись
5. Видит контактные данные читателя
6. Может отправить напоминание
7. После возврата отмечает книгу как возвращённую
